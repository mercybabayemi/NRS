What we are trying to build:
We are building a data intelligence platform, not a notebook app
so we should extract our analytics logic into a Python service, 
expose it via FastAPI as JSON endpoints, 
and let the frontend render the dashboard exactly as designed in Figma.

We simply use our analysis drawn from data and design a  data analytics 
backend that computes tax intelligence metrics and exposes
them as APIs that a frontend dashboard can consume in real time.

We already have a custom frontend design (Figma)
We want a clean API contract
We want separation of concerns:
data
business logic
presentation


We may later:
add authentication
scale on the platform
integrate with other systems (NRS, FIRS, state systems)
